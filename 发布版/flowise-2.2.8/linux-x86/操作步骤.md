# flowise-2.2.8 离线一键安装 — linux-x86

1. 下载本目录全部 11 个分包和一键安装脚本，保持文件名不变，放在同一目录。分包是标准 GZip，单个不能独立安装；脚本按顺序组合并校验完整包。
2. Linux x86_64：执行 bash 一键安装.sh；Docker 未安装或未启动时执行 sudo bash 一键安装.sh。
3. 安装完成打开 http://localhost:3000，按页面提示初始化本机账号。

包内包含固定版本的全部 Docker 镜像、Docker Engine 29.9.0、Compose 5.6.0、Python 3.14.8、项目脚本、上游许可。安装入口只加载包内镜像，禁止拉取镜像，不在线安装依赖。

分包用于满足 GitHub 普通仓库单文件 100 MiB 限制。每个分包校验值已写入脚本；组合后 TAR SHA-256：`cddd211c000800382ec022741ccdde29ee5e740830352f5e31b1759517857a1e`。

Windows 使用本项目独立 WSL 发行版与包内 Docker Engine；不需要 Docker Desktop。Linux 保留已有 Docker，未运行时启用本项目独立 Engine。包内独立 Engine 不修改系统防火墙规则。需要兼容内核、cgroups 与系统启用的虚拟化功能。

预留至少离线包体积的 8 倍磁盘空间。解压数据在 `.offline-runtime`，容器数据在 Docker 私有存储中；不要把运行数据、账号、密钥和备份上传 GitHub。

离线安装交付软件页面和运行环境。模型权重、第三方模型 API、服务商插件另行配置，未包含真实 DeepSeek 调用。Dify 的插件安装、云 API 和联网功能不属于离线安装步骤。

备份前停止服务；包内 `kit/installer.py` 支持 status、stop、start、logs、backup。Windows 在对应 WSL 内使用包内 Python；Linux可在包内 `kit/install-offline.sh` 后附相同动作。备份含账号和密钥，仅留本机。

## Flowise 登录

安装时自动生成用户名 `local-admin` 和随机密码。密码只在本机运行目录的 `.env` 中；浏览器使用该账号登录，无需再次创建管理员。不要将 `.env`、密码或运行目录发给他人或上传 GitHub。

使用包内独立 Engine 时查看 `sudo cat /var/lib/ai-news-offline/ai-news-flowise-2-2-8/runtime/.env`；使用已有 Docker 且以普通用户安装时，查看 `.offline-runtime/package/kit/runtime/.env`。

Linux 离线依赖以 Debian 12 amd64 构建；建议 Debian 12 或兼容的 glibc 系统。需要 bash、tar、gzip、sha256sum、setsid，以及内核 namespaces/cgroups 支持。当前 Linux 入口在本机 WSL2 验证，独立 Linux 主机未验收。
