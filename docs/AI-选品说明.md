# AI 工具选品与交付范围

| 项目 | 固定版本 | 场景 | 许可证关键点 | 当前状态 |
|---|---|---|---|---|
| Dify | 1.17.1 | 工作流、应用原型 | 修改 Apache，保留品牌，多租户需授权 | 安装包待实机验收 |
| n8n | 2.42.6 | 自动化与 API 串联 | SUL 与商业部分，客户自有部署服务 | 安装包待实机验收 |
| Flowise | 3.1.4 | 可视化 AI 聊天流程 | Apache 与 enterprise 商业混合 | 候选待实机验收 |
| AnythingLLM | 1.17.0 | 自用知识库与聊天 | 主项目 MIT，依赖/模型单独审核 | 候选待实机验收 |

选品依据是安装复杂度、明确的自用场景和可提供的配置劳动，不是销量或盈利证据。无需购买本包也能按官方文档自行安装。推荐先完成 Dify/n8n 小规模实机验收与有限售后，再考虑其余两个候选；不用未经核实的“全离线、无限调用、永久更新、官方授权”卖点。

Open WebUI 等项目许可包含额外品牌条件，暂不扩入本批，避免仅看 SPDX 就认定可白标转售。Flowise 同样保留混合许可并禁止解锁企业功能。

## 后续执行与额度

进度在 INSTALL-KITS-STATUS.json 中。当前没有可读取 ChatGPT 账户额度或精确重置时间的接口；这个文件不是额度检测器。没有 Docker/Windows/客户服务地址时，定时重试也不会解决实机验收。可设置定时条件续跑检查，但它只读取进度并重试可执行的未完成事项，无法报告精确的额度重置；遇到缺少实际测试环境应跳过，不能不停空跑。用户提供测试环境后可继续部署验收，不需重新选品或生成脚本。

已创建“续跑 AI 安装包任务”，按小时检查仓库进度，只续做没有外部阻塞且未被活动工作占用的事项；不能直接检测账户额度，缺少实机环境时不重复空跑。
